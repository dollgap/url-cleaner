# 링크 깔끔이

인스타·스레드·쿠팡·유튜브 같은 공유 링크 뒤에 따라붙는 **추적 꼬리표**(`igsh`, `utm_source`,
`fbclid` …)를 잘라내고 원본 주소만 남겨 주는 웹앱입니다.

**링크는 어디로도 전송되지 않습니다.** 잘라내기·복사가 모두 브라우저 안에서만 일어나고,
인터넷이 끊겨 있어도 동작합니다(첫 방문 뒤 캐시).

## 쓰는 법

1. https://dollgap.github.io/url-cleaner/ 를 안드로이드 크롬으로 엽니다.
2. 주소창 오른쪽 메뉴 → **홈 화면에 추가 / 앱 설치** 를 누르면 앱처럼 열립니다.
3. 링크를 붙여넣으면 자동으로 정리되고 **깨끗한 링크 복사** 로 바로 씁니다.
4. (선택) 다른 앱에서 **공유 → 링크 깔끔이** 로 보내면 공유된 링크가 자동으로 정리됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (HTML·CSS·JS 단일 파일, 외부 라이브러리 없음) |
| `manifest.json` | 홈 화면 추가용 웹앱 매니페스트 (`share_target` 포함) |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` | 앱 아이콘 |
| `.nojekyll` | GitHub Pages에서 Jekyll 처리 없이 그대로 배포 |
| `tools/make_icons.py` | 아이콘 생성 스크립트 (배포에는 영향 없음) |

## 로컬에서 확인

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```
